# Views

LJ OS views render the same vault-local JSON generated by the standalone
plugin. They only change how the Git Wall appears in your Daily Note.

Rendering is cached-data-only. Inserting a Git Wall does not wait for startup,
interval, view-open, or manual scanning. If **Refresh in background when LJ OS
view opens** is enabled, LJ OS shows cached data first and refreshes stale scan
data quietly for next time.

Discovery from scan roots is manual. Views never crawl folders, rediscover
repos, or scan raw drive roots.

For a complete rendered Markdown sample, see the
[Example Output](../README.md#example-output).

## Dashboard Layout

Use **Dashboard Layout** in settings to choose the order of the main generated
sections:

1. Git Scoreboard
2. Repository Activity
3. Cleanup Checklist

Use **Move up** and **Move down** to reorder sections. Disabled move buttons
mean that section is already at the top or bottom. Use **Reset layout** to
restore the default order.

Dashboard Layout affects generated Git Wall / Daily Note output only. It does
not change scan roots, tracked repositories, automation, JSON storage, or the
contents of each section.

## Summary Styles

- **Callout**: the default Obsidian summary callout.
- **Scoreboard**: a stat table with one metric per row.
- **Pit Wall**: interpreted status for activity, cleanup, push, and sync.

## Repository Views

- **Table**: renders repos in a markdown table.
- **Status Cards**: renders each repo as a success or warning callout.

## Table Formats

- **Compact**: repo, branch, status, commits.
- **Standard**: repo, branch, commits, status, unpushed, behind, latest.
- **Detailed**: standard plus repo path.
- **Emoji Board**: visual activity/tidy/push/pull board.

## Tidy Views

- **Queue**: simple list of dirty repos.
- **Shutdown Checklist**: checkbox list for tidy-up, push review, and sync
  review.

## Customized Labels

Enable **Show customized label settings** to edit:

- Daily section heading
- Summary title
- Repository section title
- Tidy-up section title

Use **Reset labels** to restore defaults. Resetting labels changes settings
only; existing notes update the next time you insert or replace the Git Wall.

Changing the Daily section heading changes the marker LJ OS uses to find and
replace the block. If you change it after inserting a Git Wall, delete or
rename the old section once.

## Suggested Combinations

### Quick Dashboard

- Summary style: `pit-wall`
- Repo view: `table`
- Table format: `emoji-board`
- Tidy view: `queue`

### Focus Mode

- Summary style: `callout`
- Repo view: `status-cards`
- Tidy view: `queue`

### Shutdown Checklist Mode

- Summary style: `pit-wall`
- Repo view: `table`
- Table format: `compact`
- Tidy view: `shutdown-checklist`

### No-Emoji Professional Mode

- Use emoji: off
- Summary style: `scoreboard`
- Repo view: `table`
- Table format: `standard`
- Tidy view: `shutdown-checklist`
